# Шаблон React + TypeScript + Effector

Шаблон представляет собой простую плоскую структуру для React проекта, предполагает использование Tanstack React Query

## Технологии
- react@18.3.1
- react-dom@18.3.1
- webpack@5.91.0
- typescript@5.4.5

## Структура
- *api* - апи слой (инициализацию http-клиента, работа с эндпоинтами и т.д).
- *assets* - статичные ресурсы (картинки, шрифты и т.д)
- *components* - общие компоненты проекта
- *constants* - константы
- *enums* - enum'ы
- *hocs* - компоненты высшего порядка (high-order components)
- *hooks* - хуки
- *pages* - страницы приложения
- *types* - типы приложения
- *utils* - утилиты
